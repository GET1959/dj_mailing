# dj_mailing
## Приложение для автоматической рассылки сообщений

Для запуска приложения необходимо создать файл .env и заполнить его в по образцу .env.sample.

Создать базу данных:

    psql -U postgres

    create database <name>

Применить миграции:

    python manage.py migrate

Создать администратора:

    python manage.py csu

Заполнить базу тестовыми данными или из фикстур, или командой.

Приложение запускается командой:

    python manage.py runserver

Пользователи создаются регистрацией на сайте, группы для них устанавливаются в админке.

    
Рассылка запускается файлом runapjobs.py
Можно также запустить при запуске приложения, если в jobs/apps.py раскомментировать def ready.
